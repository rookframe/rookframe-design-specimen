# Specimen workflow

Silkbound Ledger is canonical. The Main Menu stays Silkbound; auxiliary
Fantasy/Cyberpunk examples explore proposed System shell theming only.

Before changing a recipe, read its UI Kit contract and `README.md` here.
Instance the pinned production resources; keep synthetic content/actions local.
Component implementation belongs in rookframe-ui-kit, host behavior in
rookframe-godot. Use stock Godot scenes, Controls, Containers, Themes and signals.

Import and run `tests/specimen.gd` after changes. Inspect affected examples at
1920 × 1080, 1024 × 768 and 844 × 390, including long content, locale, interaction
states, interrupted motion and reduced motion. Keep screenshots/logs outside
source control and attach review evidence to Linear RFG-367 or the owning issue.

Repository prose guides agents to resources and checks. Human discussion lives
in the Linear document linked from README. Keep the dependency pin and displayed
source information synchronized; do not claim a Git commit is a published release.
